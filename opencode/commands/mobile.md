# Objetivo

Analizar y optimizar completamente la experiencia móvil del proyecto inmobiliario.

Debes priorizar:

- mobile-first
- velocidad móvil
- UX táctil
- conversión móvil
- Core Web Vitals
- CLS
- experiencia inmobiliaria premium

---

# Analizar

## Responsive

Revisar:

- breakpoints
- overflow horizontal
- elementos fuera de pantalla
- grids
- paddings
- márgenes
- tamaños de texto

Validar:
- teléfonos pequeños
- tablets
- dispositivos modernos

---

## Navegación móvil

Analizar:

- NavbarV3
- menús móviles
- navegación táctil
- accesibilidad táctil
- facilidad de uso

---

## Sliders y galerías

Revisar:

- PropertyGallery
- Embla Carousel
- sliders pesados
- CLS generado
- lazy loading

Priorizar:
- fluidez
- velocidad
- estabilidad visual

---

## Conversión móvil

Analizar:

- MobileStickyCTA
- botones WhatsApp
- formularios
- banners
- CTAs

Detectar:
- botones difíciles de tocar
- elementos molestos
- exceso visual

---

## Performance móvil

Revisar:

- imágenes pesadas
- hydration innecesaria
- render blocking
- JavaScript excesivo
- animaciones innecesarias

Priorizar:
- carga rápida
- interacción rápida
- estabilidad visual

---

## UX inmobiliaria móvil

El sitio debe sentirse:

- premium
- moderno
- rápido
- limpio
- fácil de navegar
- confiable
