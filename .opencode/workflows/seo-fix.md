# SEO FIX WORKFLOW

## Objetivo

Corregir problemas SEO del proyecto inmobiliario de forma segura, priorizada y sin romper performance, responsive o UX.

---

# Contexto obligatorio

Antes de comenzar debes revisar:

- AGENTS.md
- DESIGN.md
- audits/seo-audit-2026-05.md
- audits/performance-audit-2026-05.md

---

# Prioridades del workflow

Prioridad máxima:

1. Core Web Vitals
2. SEO técnico
3. Responsive móvil
4. UX inmobiliaria
5. Conversión

---

# Metodología de trabajo

## FASE 1 — Análisis

Debes:

1. Leer auditorías existentes
2. Detectar problemas críticos
3. Detectar quick wins
4. Identificar archivos afectados
5. Evaluar riesgo técnico

---

## FASE 2 — Priorización

Clasificar problemas:

### CRÍTICO

Problemas que afectan:
- indexación
- Core Web Vitals
- renderizado
- SEO técnico severo

### ALTO

Problemas que afectan:
- CTR
- metadata
- UX
- mobile performance

### MEDIO

Problemas secundarios o mejoras progresivas.

---

# Reglas importantes

Nunca:

- romper responsive
- empeorar Core Web Vitals
- eliminar metadata importante
- romper App Router
- duplicar componentes
- empeorar UX móvil

---

# Validaciones obligatorias

Antes de cualquier cambio validar:

- impacto SEO
- impacto mobile
- impacto performance
- impacto visual
- impacto en navegación

---

# Estrategia recomendada

Priorizar primero:

1. CLS
2. loading.tsx
3. OG images
4. force-dynamic innecesario
5. JSON-LD faltante
6. sitemap
7. canonicals

---

# Flujo correcto

1. Analizar
2. Explicar problema
3. Explicar solución
4. Esperar aprobación
5. Implementar
6. Validar localhost
7. Validar responsive
8. Generar resumen técnico

---

# Entrega esperada

Debes entregar:

1. Problema corregido
2. Archivos modificados
3. Impacto SEO esperado
4. Riesgo técnico
5. Validaciones necesarias

---

# Restricción importante

Nunca aplicar múltiples cambios críticos simultáneamente.

Trabajar incrementalmente.
