# Objetivo

Analizar y mejorar el diseño visual y experiencia UX del proyecto inmobiliario.

El sitio debe sentirse:

- premium
- moderno
- limpio
- elegante
- rápido
- confiable
- profesional

---

# Analizar

## Jerarquía visual

Revisar:

- tamaños de texto
- espaciados
- contraste
- orden visual
- distribución de contenido
- claridad de lectura

Detectar:
- saturación visual
- bloques desordenados
- exceso de elementos

---

## Diseño inmobiliario

Validar:

- apariencia premium
- sensación de confianza
- claridad de propiedades
- experiencia de exploración
- facilidad de navegación

Priorizar:
- fotografías
- cards
- CTAs
- búsqueda

---

## Componentes críticos

Analizar especialmente:

- NavbarV3
- HomeHeroV3
- SearchBarV3
- PropertyCardV3
- PropertyGallery
- FooterV3
- ListingConversionBanner
- MobileStickyCTA

---

## Tipografía

Validar:

- legibilidad
- tamaños móviles
- jerarquía H1-H6
- consistencia visual

Mantener:
- Poppins
- estilo moderno

---

## Colores

Revisar:

- contraste
- consistencia
- percepción premium
- accesibilidad

Evitar:
- colores agresivos
- saturación excesiva
- demasiados colores

---

## Responsive Design

Analizar:

- experiencia móvil
- grids
- alineaciones
- spacing
- tamaños táctiles

Nunca:
- romper mobile-first
- romper desktop

---

## Conversión visual

Revisar:

- CTAs
- botones
- banners
- formularios
- WhatsAppFloatingButton

Detectar:
- elementos poco visibles
- baja prioridad visual
- exceso de distracción

---

## Performance visual

Detectar:

- animaciones innecesarias
- sliders pesados
- imágenes mal optimizadas
- efectos visuales excesivos

Priorizar:
- fluidez
- limpieza
- velocidad

---

# Diseño esperado

El sitio debe parecer:

- inmobiliaria moderna
- startup premium
- plataforma rápida
- marca confiable

---

# Anti-patrones

Nunca:

- usar sombras excesivas
- saturar la interfaz
- usar demasiados colores
- romper consistencia
- crear componentes duplicados
- empeorar Core Web Vitals

---

# Entrega esperada

Debes entregar:

1. Problemas visuales encontrados
2. Impacto UX
3. Solución recomendada
4. Componentes afectados
5. Resultado visual esperado

---

# Reglas importantes

- Mantener diseño premium
- Mantener responsive
- Mantener velocidad
- Priorizar experiencia móvil
- Reutilizar design-system existente
